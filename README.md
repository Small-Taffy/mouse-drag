## English

An action-queue mod for **Don't Starve single-player** (base game, Reign of Giants, Shipwrecked, Hamlet). Drag with the mouse to batch-select entities or ground points, and the character will execute all matched actions in order — chop, mine, dig, plant, build, cook, dry, fish, read and more.

### Features

- **Shift + LMB / RMB drag** — rectangle-select entities to queue left/right-click actions
- **Shift + quick click** — queue all same-prefab entities around the cursor
- **Quick-Queue key (default C)** — queue all actionable entities around the player (`Ctrl + key` for right-click actions)
- **Craft key (default X)** — craft the last recipe; `Shift + key` for a full craft queue
- **Ctrl + Alt + RMB** — read/eat queue for books and food
- **Area planting / building** — drag on ground to preview a square or hexagon grid of points
- **Special queues** — cookpots, drying racks, fishing ponds handled intelligently
- **Optional modules** — item finder, range display, short actions, spacing override, 21×21 turf grid (default F2)

### Installation

1. Download the latest release and extract into your mods folder:
   - Windows: `...\steamapps\common\dont_starve\mods\`
   - macOS: `~/Library/Application Support/Steam/steamapps/common/dont_starve/mods/`
   - Linux: `~/.steam/steamapps/common/dont_starve/mods/`
2. Enable **Mouse Drag** in the in-game mods menu.

## 中文

适用于**饥荒单机版**（原版 / 巨人国 / 船难 / 猪镇）的动作排队模组：按住 Shift 用鼠标拖出框选区域，即可批量排队执行动作——砍树、挖矿、挖掘、种植、建造、烹饪、晾晒、钓鱼、读书等，全部自动按距离逐个完成。

### 功能一览

- **Shift + 左/右键拖拽** — 框选实体，排队左/右键动作
- **Shift + 快速点击** — 以鼠标为中心，排队周围所有同类实体
- **快速队列键（默认 C）** — 以玩家为中心排队周围可交互实体（`Ctrl + 键` 为右键动作）
- **制作键（默认 X）** — 制作上一物品；`Shift + 键` 进入制作队列
- **Ctrl + Alt + 右键** — 读书 / 进食队列
- **范围种植 / 建造** — 在地面拖拽预览正方形或六边形点位
- **特殊队列** — 智能处理烹饪锅、晾肉架、池塘钓鱼
- **可选模块** — 物品查找、范围显示、短动作、间距覆盖、21×21 地皮网格（默认 F2）

### 安装方法

1. 下载最新 Release，解压到游戏 mods 目录：
   - Windows：`...\steamapps\common\dont_starve\mods\`
   - macOS：`~/Library/Application Support/Steam/steamapps/common/dont_starve/mods/`
   - Linux：`~/.steam/steamapps/common/dont_starve/mods/`
2. 在游戏内模组菜单中启用 **Mouse Drag**。
